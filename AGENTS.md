## Etapa actual: desarrollo visual del frontend

Actualmente el proyecto se encuentra en la etapa de diseño y construcción visual del frontend.

Reglas:

- Trabajar exclusivamente en Vue 3 y Vite.
- No integrar todavía Laravel API.
- No utilizar Axios para obtener información.
- No implementar todavía Pinia.
- Utilizar datos simulados y locales para productos, categorías, usuarios y demás elementos.
- Las interacciones deben funcionar mediante el estado reactivo de Vue.
- Los componentes deben diseñarse pensando en su futura integración con una API REST.
- Separar la lógica visual de la lógica de negocio cuando sea conveniente.
- No introducir dependencias innecesarias.

El objetivo de esta etapa es conseguir un frontend visualmente completo, responsive, interactivo y consistente con SHOP.md, que es la referencia visual principal durante esta etapa.

La integración con Laravel, Axios y Pinia se realizará en una etapa posterior.
